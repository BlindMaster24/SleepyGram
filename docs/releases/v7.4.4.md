### Автообновления через GitHub

SleepyGram проверяет наличие новых версий в GitHub Releases. Нажмите **«Обновить до …»** в настройках, чтобы скачать подписанный пакет и перезапустить клиент. Ручная проверка доступна при выключенной фоновой проверке.

Установите v7.4.4 вручную один раз. Следующие выпуски можно будет ставить прямо из клиента на Windows x64, macOS arm64 и Linux x64.

### Исправление названия в настройках

Раздел **SleepyGram Preferences** отображает актуальное название. Раньше старый язык или сохранённый перевод мог вернуть надпись **AyuGram Preferences**.
